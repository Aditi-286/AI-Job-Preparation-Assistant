# 🤖 AI Job Preparation Assistant

An AI-powered web application that helps students prepare for IT placements by generating personalized career roadmaps, identifying skill gaps, recommending projects, and providing AI-powered interview practice.

## 🚀 Features

- User registration and login
- Career profile
- Target job selection
- Current skills tracking
- AI skill-gap analysis
- Personalized preparation roadmap
- 12-week preparation plan
- AI interview question generation
- AI interview answer evaluation
- AI project recommendations
- Progress tracking dashboard
- SQLite database
- Password hashing
- Flask backend
- Responsive frontend
